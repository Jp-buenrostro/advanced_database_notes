# Session – 2026-02-12

## Topics covered
- SELECT
    Es para elegir qué columnas queremos ver de una tabla 
- LIMIT
    Limita la cantidad de resultados que se devuelven
- DISTINCT
    Sirve para eliminar valores repetidos en los resultados y mostrar solo valores unicos
- FROM
    Indica de qué tabla se van a obtener los datos.
- WHERE
    Agrega condiciones para filtrar los resultados 
- ORDER BY
    Ordena los resultados de una columna en especifico (ASC / DESC)

## What I understood
- Aprendí como seleccionar columnas de una tabla con SELECT y evitar duplicados usando DISTINCT. 
También entendí cómo obtener datos con FROM y como condicionar los datos que devuelven con WHERE. 
También aprendí a ordenar resultados con ORDER BY de forma ASC o DESC

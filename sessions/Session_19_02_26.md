# Session – 2026-02-19

## Topics covered
- Tablas
Una tabla es una estructura en la base de datos donde se almacenan datos organizados en filas y columnas.
- Primary and foreign keys
Primary key: identificador de cada registro de una tabla
Foreign key: conecta una tabla con otra usando la clave primaria de la otra tabla.
- JOIN
Combina datos de tablas 
- INNER JOIN
- RIGHT / LEFT JOIN
- CROSS JOIN
Combina cada fila de una tabla con todas las filas de la otra


## What I understood
- Para hacer JOIN entre tablas es necesario que exista una relación entre ellas, normalmente se usa una foreign key que coincida con la primary key de otra tabla
